1. 📖 Apa Itu GitHub & Kenapa Kita Pakai Ini? (Khusus Pemula)

Bayangkan kita ber-6 sedang merakit 1 instrumen Siklotron DECY-13 menggunakan AI masing-masing di laptop yang berbeda. Kalau kita kirim file lewat WhatsApp atau Flashdisk, file-nya pasti tertukar dan saling menimpa!

GitHub adalah "Google Drive khusus kodingan" yang punya fitur pintar bernama Branch (Cabang). Dengan Branch, 6 orang bisa mengedit proyek di waktu bersamaan secara online, lalu digabungkan (Merge) menjadi satu kesatuan yang utuh.

6 Istilah GitHub yang Wajib Kamu Tahu (Bahasa Manusia):

1. Repository (Repo) Folder proyek utama kita di internet:
github.com/azfaaksan-hub/sp-aksel-polteknuklir
2. Clone (Kloning) Mendownload seluruh folder proyek dari GitHub ke laptopmu (cukup dilakukan 1 kali saja di awal).
3. Branch (Cabang Kerja) Ruang kerja pribadimu (misal divisi-3-led-ws2812b) supaya kodinganmu tidak mengganggu teman lain.
4. Pull (Tarik Update) Menarik update terbaru dari server GitHub ke laptopmu sebelum mulai kerja.
5. Commit & Push (Simpan & Upload) Menyimpan perubahan di laptop (Commit) lalu mengunggahnya ke GitHub online (Push).
6. Pull Request & Merge (Gabung) Meminta Ketua Tim (Divisi 1 - Core Raspi) menggabungkan hasil kerjamu ke program utama (main).

3. 💻 Instalasi & Setup Pertama Kali (Cukup Sekali Saja!)

Ikuti 4 langkah berurutan ini di laptop Windows kamu supaya terhubung ke proyek GitHub kelompok kita:

1

Buat Akun GitHub & Minta Undangan Akses (Collaborator)

1. Buka https://github.com lalu daftar akun gratis (jika belum punya).
2. Kirimkan username GitHub atau emailmu ke Ketua Tim (Divisi 1).
3. Ketua Tim akan mengundangmu di menu Settings → Collaborators → Add people pada repositori azfaaksan-hub/sp-aksel-polteknuklir. Klik Accept Invitation di emailmu!

2

Install Git & Pilih Cara Kerja (Bisa Pakai Aplikasi Klik GUI atau Terminal)

Download dan install kedua software gratis ini (klik Next → Next → Finish saja):

  • Wajib: Git for Windows → https://git-scm.com/download/win
  • Sangat Direkomendasikan untuk Pemula: GitHub Desktop → https://desktop.github.com (Aplikasi visual tinggal klik tombol tanpa perlu hafal perintah terminal!).
3

Kenalkan Nama & Emailmu ke Git (Jika Menggunakan Terminal / VS Code)

Buka PowerShell atau Terminal di VS Code, lalu salin dan jalankan perintah ini (ganti dengan nama dan email GitHub kamu):

PowerShell / Terminal (Sekali Saja)
git config --global user.name "Nama Kamu"
git config --global user.email "emailkamu@gmail.com"
4

Download Proyek (Clone) & Masuk ke Cabang (Branch) Divisimu

Jika pakai GitHub Desktop (Cara Visual):
Klik File → Clone Repository → URL → ketik https://github.com/azfaaksan-hub/sp-aksel-polteknuklir.git → Klik Clone. Setelah selesai, klik menu Current Branch di bagian atas, lalu pilih atau buat branch sesuai divisimu (misal: divisi-2-vakum-safety).

Jika pakai Terminal / PowerShell (Cara Cepat):

PowerShell — Clone & Buat Branch Divisi
# 1. Download folder proyek ke laptopmu
git clone https://github.com/azfaaksan-hub/sp-aksel-polteknuklir.git
cd sp-aksel-polteknuklir

# 2. Masuk ke branch sesuai divisimu (GANTI nama branch sesuai tabel Divisi 2-6!)
# Contoh untuk Divisi 2:
git checkout -b divisi-2-vakum-safety

4. 🔄 Penggunaan Berkala Harian ("Agar Progres Online & Update Terus")

Setiap kali kamu mau mulai mengerjakan proyek bersama AI dan setiap kali selesai, lakukan Ritual 3 Langkah ini. Pilih tampilan panduan yang paling nyaman buatmu:

🖱️ Rutinitas Harian dengan Aplikasi GitHub Desktop (Tanpa Ketik Kode Git)

🌅 A. SEBELUM MULAI KERJA 1. Buka aplikasi GitHub Desktop.
2. Pastikan kotak Current Branch di atas bertuliskan nama branch divisimu (misal divisi-3-led-ws2812b).
3. Klik tombol Fetch origin (atau Pull origin) di kanan atas, lalu klik Branch → Update from main agar kamu mendapat update terbaru dari Ketua Tim!
🤖 B. SAAT NGODING BERSAMA AI 1. Klik tombol Open in Visual Studio Code (atau buka folder proyek di AI pilihanmu).
2. Salin Prompt Divisimu dari Bagian 5 di bawah ke AI.
3. Pastikan di bagian kiri GitHub Desktop (Changes), file yang berubah HANYA file jatah divisimu.
🌙 C. SETELAH SELESAI (BIAR ONLINE) 1. Buka kembali GitHub Desktop.
2. Di pojok kiri bawah, isi kotak Summary (contoh: Perbaiki efek trail LED spiral).
3. Klik tombol biru Commit to divisi-...
4. Klik tombol Push origin di kanan atas!
5. Klik Create Pull Request jika ingin digabung oleh Ketua.

⌨️ Rutinitas Harian dengan Terminal (Copy-Paste 3 Blok Ini)

🌅 A. Sebelum Mulai Kerja (Ambil Update Terbaru dari Main):

1. Tarik Update Terbaru dari Server GitHub
git fetch origin
git merge origin/main

🔍 B. Cek File Apa Saja yang Diubah oleh AI Kamu:

2. Cek Status File (Pastikan Hanya File Divisimu yang Berubah!)
git status

🌙 C. Setelah Selesai Kerja (Simpan & Upload Online ke GitHub):

3. Simpan (Commit) & Upload (Push) ke GitHub Online
# Tambahkan semua perubahan di file divisimu
git add .

# Simpan catatan perubahan
git commit -m "Update progres modul divisi saya"

# Upload ke branch divisimu di GitHub (otomatis online!)
git push -u origin HEAD
