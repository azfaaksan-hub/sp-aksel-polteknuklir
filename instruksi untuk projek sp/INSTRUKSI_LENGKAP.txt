  BAGIAN A : GAMBARAN UMUM SISTEM
================================================================================

  [MINI PC] ----(WiFi/LAN)----> [Mosquitto Broker di RPi] <---- [RPi 3B+]
      |                                                               |
  Web HMI                                              Hardware GPIO/SPI/DMA
  (index.html)                                         - LED WS2812B (GPIO 18)
  MQTT.js                                              - Relay Kipas (GPIO 21)
  ws://192.168.137.1:9001                              - Buzzer (GPIO 17)
                                                       - LCD ILI9341 (SPI0)
                                                       - E-Stop (GPIO 22)

  Alur Data:
  1. Tombol di Web HMI diklik
  2. MQTT Publish ke topic: decy13/hmi/cmd  (format JSON)
  3. Daemon Python di RPi 3B+ menerima perintah
  4. RPi menggerakkan hardware nyata (LED, Kipas, Buzzer, LCD)
  5. RPi Publish keadaan nyata ke: decy13/rpi/state (tiap 200ms)
  6. Web HMI menerima telemetri & semua animasi mengikuti data RPi

================================================================================
  BAGIAN B : WIRING (SAMBUNGAN KABEL)
================================================================================

  --- B1. LED STRIP WS2812B 5V (64 Piksel, Seri dari Spiral ke Shoot) ---

  WS2812B             Raspberry Pi 3B+
  ----------          ----------------
  5V  (Merah)   -->  Pin 2 (5V Power) atau sumber 5V eksternal
  GND (Hitam)   -->  Pin 6 (GND)          ** GND harus sama/common **
  DIN (Kuning)  -->  Pin 12 = GPIO 18     ** Data DMA PWM0 **

  PENTING:
  - Gunakan RESISTOR 300-470 Ohm di jalur DIN (dari GPIO 18 ke LED)
  - Jika panjang strip > 1 meter, gunakan power supply 5V TERPISAH
    (bukan dari RPi) agar arus tidak drop. GND tetap dishare ke RPi.
  - Jika pakai power supply eksternal:
      PS_EXT 5V  --> VCC Strip
      PS_EXT GND --> GND Strip + GND Pin 6 RPi (titik ground bersama)

  Urutan Piksel:
  - Piksel #0  - #47  = Segmen Spiral (di dalam area elektroda Dee)
  - Piksel #48 - #63  = Segmen Lurus Beamline (tembak ke Target)

  --- B2. MODUL RELAY KIPAS DC 12V (Active-LOW) ---

  Modul Relay 1 Channel     Raspberry Pi 3B+
  ----------------------    ----------------
  VCC   (Merah)       -->  Pin 2 (5V)
  GND   (Hitam)       -->  Pin 6 (GND)
  IN    (Kuning)      -->  Pin 40 = GPIO 21

  Sambungan Kipas 12V ke Relay:
  - COM  --> Kabel + Kipas DC 12V
  - NO   --> Sumber +12V (dari adaptor 12V)
  - (NC dibiarkan tidak terhubung)

  Logika Active-LOW:
  - GPIO 21 = LOW  (0V)  --> Relay ON  --> Kipas BERPUTAR
  - GPIO 21 = HIGH (3.3V) -> Relay OFF --> Kipas MATI

  --- B3. BUZZER SFM-27 (atau Buzzer Pasif) ---

  Buzzer              Raspberry Pi 3B+
  ------              ----------------
  + (Merah)     -->  TRANSISTOR NPN (mis. BC547) -- Kolektor
                     GPIO 17 (Pin 11) --> Basis via R 1k Ohm
                     Emiter --> GND
  - (Hitam)     -->  GND

  Atau (buzzer aktif 3.3V langsung):
  + (Merah)     -->  Pin 11 = GPIO 17  (arus max 16 mA)
  - (Hitam)     -->  Pin 6  (GND)

  --- B4. LCD TFT 2.4/2.8 inch SPI (Driver ILI9341, 320x240) ---

  LCD Module Pin      Raspberry Pi 3B+ (SPI0 Hardware)
  --------------      --------------------------------
  VCC               -->  Pin 17 (3.3V) ATAU Pin 2 (5V sesuai modul)
  GND               -->  Pin 6  (GND)
  CS  (CE0)         -->  Pin 24 = GPIO 8   (SPI0 CE0)
  RESET             -->  Pin 22 = GPIO 25  (RST dikontrol luma.lcd)
  DC  (A0/RS)       -->  Pin 18 = GPIO 24  (Data/Command select)
  SDI (MOSI)        -->  Pin 19 = GPIO 10  (SPI0 MOSI)
  SCK (SCLK)        -->  Pin 23 = GPIO 11  (SPI0 SCLK)
  LED (Backlight)   -->  Pin 17 (3.3V) via R 47-100 Ohm, atau langsung 3.3V
  MISO (SDO)        -->  Pin 21 = GPIO 9   (SPI0 MISO, kadang tidak perlu)

  --- B5. TOMBOL FISIK EMERGENCY STOP (Normally-Closed ke GND) ---

  Tombol NC           Raspberry Pi 3B+
  ----------          ----------------
  Salah satu kaki --> Pin 15 = GPIO 22  (Input Pull-Up internal diaktifkan)
  Kaki lain       --> Pin 14 (GND)

  Logika:
  - Normal (NC terhubung): GPIO 22 = LOW  (0V)  --> AMAN
  - Tombol Ditekan (NC terputus): GPIO 22 = HIGH (3.3V) --> EMERGENCY STOP
  CATATAN: Kode daemon mendeteksi transisi LOW saat E-Stop ditekan.
  Periksa kembali: kode menggunakan PUD_UP + baca LOW=ESTOP.

================================================================================
  BAGIAN C : PERSIAPAN RASPBERRY PI 3 MODEL B+
================================================================================

  --- C1. Aktivasi SPI & Nonaktifkan Audio (WAJIB untuk WS2812B DMA) ---

  Jalankan di terminal RPi:

    sudo nano /boot/config.txt

  Cari baris:
    dtparam=audio=on
  Ganti menjadi:
    dtparam=audio=off

  Tambahkan di bagian bawah (jika belum ada):
    dtparam=spi=on

  Simpan (Ctrl+O, Enter, Ctrl+X), lalu reboot:
    sudo reboot

  Alternatif cepat via CLI:
    sudo sed -i 's/^dtparam=audio=on/dtparam=audio=off/' /boot/config.txt
    grep -qxF 'dtparam=spi=on' /boot/config.txt || echo 'dtparam=spi=on' | sudo tee -a /boot/config.txt
    sudo reboot

  --- C2. Install Mosquitto Broker MQTT ---

    sudo apt update && sudo apt install -y mosquitto mosquitto-clients

  Buat konfigurasi Mosquitto untuk DECY-13:

    sudo nano /etc/mosquitto/conf.d/decy13.conf

  Isi file tersebut dengan:
  ---
    listener 1883
    protocol mqtt
    allow_anonymous true

    listener 9001
    protocol websockets
    allow_anonymous true
  ---

  Restart Mosquitto:
    sudo systemctl restart mosquitto
    sudo systemctl enable mosquitto

  Verifikasi berjalan:
    sudo systemctl status mosquitto

  --- C3. Install Dependensi Python ---

    sudo apt install -y python3-pip python3-pil
    sudo pip3 install paho-mqtt>=1.6.1 RPi.GPIO rpi-ws281x luma.lcd Pillow spidev --break-system-packages

  Atau gunakan file requirements.txt:
    sudo pip3 install -r raspi_cli/requirements.txt --break-system-packages

  --- C4. Transfer File ke Raspberry Pi ---

  Dari komputer Anda (di Windows PowerShell), gunakan SCP:

    scp -r "C:\Users\ucing\agy_vscode\decy13_cyclotron_mqtt_cli_kit\decy13_mqtt_kit\raspi_cli" pi@192.168.137.1:/home/pi/decy13/

  Atau gunakan WinSCP (GUI) / FileZilla dengan protokol SFTP ke IP 192.168.137.1.

  File yang perlu ditransfer ke RPi di folder /home/pi/decy13/raspi_cli/:
    - config_hardware.json
    - 01_test_relay_buzzer.py
    - 02_test_lcd_ili9341.py
    - 03_test_led_pixel_finder.py
    - 04_decy13_mqtt_daemon.py

================================================================================
  BAGIAN E : PERBAIKAN WEB HMI (MQTT STATE-DRIVEN MURNI)
================================================================================

  Perubahan yang diperlukan di web_hmi/index.html:

  --- E1. Tambahkan Koneksi MQTT.js (sudah ada CDN-nya) ---

  Cari baris di bagian JAVASCRIPT (sekitar baris 893):
    const state = {
      ...
      wsClient: null,
      wsConnected: false,
      ...
    };

  Tambahkan variabel MQTT:
    mqttClient: null,
    mqttConnected: false,

  --- E2. Fungsi Koneksi MQTT ---

  Tambahkan fungsi ini di awal JavaScript (sebelum simulationStep):

    function connectMQTT() {
      const brokerUrl = 'ws://192.168.137.1:9001';
      const options = {
        clientId: 'hmi_decy13_' + Math.random().toString(16).substr(2, 8),
        keepalive: 30,
        clean: true,
      };
      state.mqttClient = mqtt.connect(brokerUrl, options);

      state.mqttClient.on('connect', () => {
        state.mqttConnected = true;
        state.mqttClient.subscribe('decy13/rpi/state');
        appendCommLog('INFO', 'MQTT TERHUBUNG ke Mosquitto ws://192.168.137.1:9001');
        document.getElementById('connDot').className = 'w-2 h-2 rounded-full bg-emerald-400';
        document.getElementById('connText').textContent = 'MQTT TERHUBUNG - RPi 3B+';
      });

      state.mqttClient.on('message', (topic, payload) => {
        if (topic === 'decy13/rpi/state') {
          try {
            const rpiState = JSON.parse(payload.toString());
            applyRpiState(rpiState);  // Fungsi update UI dari data RPi
          } catch(e) { console.error('Parse error:', e); }
        }
      });

      state.mqttClient.on('error', (err) => {
        appendCommLog('ERR', 'MQTT Error: ' + err.message);
      });

      state.mqttClient.on('close', () => {
        state.mqttConnected = false;
        appendCommLog('INFO', 'MQTT terputus. Reconnect otomatis...');
      });
    }

  --- E3. Fungsi Publish Perintah ke RPi ---

  Ganti fungsi broadcastToRaspberryPi() yang lama dengan:

    function publishCommand(cmdObj) {
      if (state.mqttClient && state.mqttConnected) {
        state.mqttClient.publish('decy13/hmi/cmd', JSON.stringify(cmdObj));
        appendCommLog('TX', 'CMD: ' + JSON.stringify(cmdObj));
      } else {
        appendCommLog('WARN', 'MQTT belum terhubung. Perintah tidak dikirim.');
      }
    }

  Contoh pemanggilan di event listener tombol:
    Power ON:      publishCommand({ cmd: 'TOGGLE_POWER' })
    Vacuum:        publishCommand({ cmd: 'TOGGLE_VACUUM' })
    Set Params:    publishCommand({ cmd: 'SET_PARAMS', magnet_a: 1450, rf_mhz: 22.5, rf_kv: 45, beam_ua: 8.4 })
    Interlock:     publishCommand({ cmd: 'TOGGLE_INTERLOCK' })
    Start Beam:    publishCommand({ cmd: 'START_BEAM' })
    Shoot:         publishCommand({ cmd: 'SHOOT' })
    Emergency:     publishCommand({ cmd: 'EMERGENCY_STOP' })

  --- E4. Fungsi applyRpiState() — Update UI dari Data RPi ---

  Tambahkan fungsi ini yang mengupdate state & UI dari telemetri RPi:

    function applyRpiState(rpi) {
      // Sinkronisasi state lokal dari data RPi
      state.power     = rpi.power;
      state.vacuum    = rpi.vacuum;
      state.rf        = rpi.rf;
      state.interlock = rpi.interlocks;
      state.beam      = rpi.beam;
      state.shooting  = rpi.exposureActive;
      state.estop     = rpi.emergency;

      // Sinkronisasi indeks LED (KUNCI: dari RPi, bukan dihitung lokal)
      state.activeLedIndex  = rpi.activeLedIdx >= 0 ? rpi.activeLedIdx : 0;
      state.shootLedIndex   = rpi.shootLedIdx;

      // Sinkronisasi nilai fisika
      state.vacPressureMbar  = rpi.pressure;
      state.beamEnergyMev    = rpi.beamEnergy;
      state.actualBeamUa     = rpi.beamCurrent;
      state.targetCurrentUa  = rpi.targetCurrent;
      state.exposureSeconds  = rpi.exposureSeconds;

      // Update teks LCD di Web HMI dari RPi
      if (document.getElementById('lcdLine1')) {
        document.getElementById('lcdLine1').textContent = rpi.lcd_line1 || '';
        document.getElementById('lcdLine2').textContent = rpi.lcd_line2 || '';
        document.getElementById('lcdLine3').textContent = rpi.lcd_line3 || '';
        document.getElementById('lcdLine4').textContent = rpi.lcd_line4 || '';
      }

      // Update log dari RPi
      if (rpi.logs && rpi.logs.length) {
        rpi.logs.forEach(l => appendCommLog('RX', l));
      }

      syncUiFromState();
    }

  --- E5. Panggil connectMQTT() saat halaman dimuat ---

  Di bagian paling bawah script (sebelum closing baris requestAnimationFrame):

================================================================================
  BAGIAN G : TROUBLESHOOTING UMUM
================================================================================

  MASALAH: LED WS2812B tidak menyala
  SOLUSI:  - Pastikan audio di /boot/config.txt sudah OFF
           - Pastikan jalankan dengan sudo
           - Cek resistor 300-470 Ohm di jalur DIN
           - Cek tegangan: 5V harus stabil (ukur dengan multimeter)

  MASALAH: LCD tidak menampilkan gambar
  SOLUSI:  - Jalankan: ls /dev/spidev* (harus ada /dev/spidev0.0)
           - Cek wiring DC (GPIO 24) dan RST (GPIO 25)
           - Cek backlight: LED pin LCD terhubung ke 3.3V via R 100 Ohm

  MASALAH: MQTT tidak terhubung dari Web HMI
  SOLUSI:  - Pastikan Mosquitto berjalan: sudo systemctl status mosquitto
           - Pastikan port 9001 (WebSocket) ada di config Mosquitto
           - Pastikan Mini PC & RPi di jaringan yang SAMA
           - Di Chrome, buka Developer Tools (F12) > Console untuk cek error
           - Jika buka via file://, beberapa browser blokir WebSocket — 
             gunakan python3 -m http.server untuk serve via http://

  MASALAH: Relay tidak merespons
  SOLUSI:  - Cek tegangan VCC relay module: harus 5V
           - Cek LED indikator di modul relay (harus nyala saat aktif)
           - Cek apakah modul Active-LOW atau Active-HIGH, sesuaikan kode

  MASALAH: E-Stop tidak bekerja
  SOLUSI:  - Cek konfigurasi PIN 22 (harus INPUT dengan PULL_UP internal)
           - Cek sambungan tombol NC ke GND
           - Uji manual: short GPIO 22 ke GND dengan kabel, daemon harus STOP
