📖 Gambaran Umum — Apa itu DECY-13?

DECY-13 adalah akselerator siklotron 13 MeV untuk ion H⁻ (hidrogen negatif) yang dikembangkan di BRIN. Proyek ini membuat alat peraga interaktif yang mensimulasikan cara kerja siklotron tersebut menggunakan perangkat nyata dan antarmuka komputer.

💡 Analoginya sederhana: Bayangkan siklotron seperti putaran bola golf yang dipercepat secara spiral. Partikel dimulai dari tengah, dipercepat oleh medan RF, berputar makin lebar karena magnet, lalu "ditembakkan" ke target saat mencapai energi 13 MeV.

Apa yang kita buat?

🍓
Raspberry Pi 3B+
Otak sistem — mengendalikan semua hardware nyata: LED strip spiral, kipas vakum, buzzer, dan layar LCD. Mengirim data ke Web HMI setiap 200ms.
🖥️
Web HMI (Mini PC)
Ruang kontrol digital — tampilan animasi siklotron 2D, grafik tekanan & arus, dan tombol kendali. Semua animasinya mengikuti hardware nyata di RPi.
📡
MQTT (Mosquitto Broker)
Penghubung komunikasi antara Web HMI dan RPi. Seperti "WhatsApp" antara dua perangkat — perintah dan status data dikirim via jaringan lokal.

⚡ Alur 7 Tahap Operasional Siklotron

Inilah urutan yang harus dilakukan saat demo. Tidak boleh dilewati!

1
TAHAP 1 Inisiasi Sistem — POWER ON
Klik saklar Power di Web HMI. RPi akan menerima perintah dan membunyikan buzzer 5 detik sebagai tanda sistem aktif. LED #0 menyala biru tanda standby.
{"cmd": "TOGGLE_POWER"}
2
TAHAP 2 Input Parameter HMI
Atur nilai parameter fisika: Arus Magnet (1450 A), Frekuensi RF (22.5 MHz), Tegangan Dee (45 kV), dan Arus Berkas target (8.4 µA). Parameter dikirim ke RPi.
{"cmd": "SET_PARAMS", "magnet_a": 1450, "rf_mhz": 22.5, "rf_kv": 45, "beam_ua": 8.4}
3
TAHAP 3 Transmisi MQTT
Setiap klik tombol di Web HMI otomatis mengirim perintah JSON lewat jaringan MQTT ke RPi. RPi menerima dan langsung merespons hardware nyata. Tidak ada delay besar — komunikasi real-time!
4
TAHAP 4 Vakum Aktif — Pompa Ruang Hampa
Klik VACUUM di HMI. Relay GPIO 21 aktif → kipas DC 12V berputar mensimulasikan pompa vakum. Tekanan turun secara eksponensial dari 1013 mbar menuju 1.2×10⁻⁷ mbar. LCD RPi menampilkan tekanan real-time.
{"cmd": "TOGGLE_VACUUM"} → Kipas berputar → Pressure turun
5
TAHAP 5 Safety Interlock & LCD
Saat tekanan mencapai ≤ 1×10⁻³ mbar, tombol INTERLOCK bisa diklik. LCD TFT SPI menampilkan "BEAM READY". Ini adalah kunci keselamatan — beam tidak bisa dinyalakan tanpa vakum yang cukup!
{"cmd": "TOGGLE_INTERLOCK"} → hanya aktif jika P ≤ 1e-3 mbar
6
TAHAP 6 Akselerasi Spiral — START BEAM
Klik START BEAM. LED strip WS2812B di dalam area elektroda Dee mulai berputar spiral dari tengah ke luar, makin cepat seiring energi meningkat menuju 13 MeV. Indeks LED aktif dikirim RPi tiap 200ms ke HMI sehingga animasi sinkron persis dengan LED fisik!
{"cmd": "START_BEAM"} → activeLedIdx naik → animasi spiral HMI ikut
7
TAHAP 7 Ekstraksi & Tembak Target
Klik SHOOT EXPOSURE. LED segmen beamline (piksel 48–63) menyala oranye menembak ke arah target. Buzzer berbunyi beep berulang tanda iradiasi aktif. Timer iradiasi berjalan. Tekan lagi untuk menghentikan.
{"cmd": "SHOOT"} → shootLedIdx aktif → buzzer beep → timer mulai
!
DARURAT Emergency Stop
Kapanpun bisa ditekan — tombol fisik GPIO 22 di RPi atau tombol merah di HMI. Semua sistem langsung mati: RF OFF, kipas OFF, LED merah semua, buzzer alarm 3 detik. Reset dengan klik Power ON lagi.
{"cmd": "EMERGENCY_STOP"} → SEMUA SUBSISTEM MATI SEKETIKA

🔌 Wiring — Sambungan Kabel GPIO

⚠️ MATIKAN RPi terlebih dahulu sebelum memasang atau melepas kabel! Semua nomor GPIO menggunakan sistem BCM (bukan nomor pin fisik).

Peta Pin Lengkap

KomponenGPIO (BCM)Pin FisikKe ManaKeterangan
💡 LED WS2812B DINGPIO 18Pin 12 via R 330Ω → DIN Strip DMA PWM0 — Audio harus OFF!
🌀 Relay Kipas INGPIO 21Pin 40 IN Modul Relay Active-LOW: LOW=ON, HIGH=OFF
🔔 Buzzer (+)GPIO 17Pin 11 Buzzer + (atau basis transistor) Active-HIGH: HIGH=bunyi
🛑 E-Stop TombolGPIO 22Pin 15 Kaki NC Tombol (COM ke GND) Input Pull-Up internal aktif
📺 LCD CS (CE0)GPIO 8Pin 24 LCD Pin CS/CE0 SPI0 Chip Select
📺 LCD MOSIGPIO 10Pin 19 LCD Pin SDI/MOSI SPI0 Data
📺 LCD SCLKGPIO 11Pin 23 LCD Pin SCK SPI0 Clock
📺 LCD DCGPIO 24Pin 18 LCD Pin DC/A0/RS Data/Command Select
📺 LCD RSTGPIO 25Pin 22 LCD Pin RESET Reset LCD
⚡ Power 5V—Pin 2 atau 4 VCC Relay, VCC LED (jika kecil) Maks 1A dari RPi header
⚡ Power 3.3V—Pin 17 VCC LCD (cek datasheet) Atau 5V jika LCD butuh 5V
⏚ GND Bersama—Pin 6, 9, 14, 25, 39 GND semua modul + PS Eksternal WAJIB common ground!
💡 Tips Urutan Wiring: Sambungkan dulu GND semua modul → lalu power (VCC) → terakhir sinyal data (GPIO). Lepas dalam urutan terbalik: sinyal → power → GND.

🚀 Mulai Cepat — Pilih Kondisi Anda

🅐 Saya di laptop, belum ada hardware RPi

  1. Install Mosquitto Windows → mosquitto.org/download
  2. Jalankan: mosquitto.exe -c mosquitto_decy13_windows.conf -v
  3. Buka PowerShell: pip install paho-mqtt
  4. Jalankan: python 05_laptop_dryrun_simulator.py
  5. Buka index.html di Chrome, URL: ws://127.0.0.1:9001
  6. Klik Hubungkan → animasi HMI aktif! ✅
📖 Panduan lengkap: PANDUAN_DRYRUN_LAPTOP_WINDOWS.txt

🅑 Saya punya RPi 3B+ dan mau setup dari nol

  1. Flash OS ke MicroSD (Raspberry Pi Imager) — aktifkan SSH saat flash
  2. SSH masuk: ssh pi@[IP_RPi]
  3. Transfer file setup: scp setup_raspi_decy13.sh pi@[IP_RPi]:/home/pi/
  4. Jalankan auto-setup: sudo bash setup_raspi_decy13.sh
  5. Reboot RPi, transfer semua file Python via WinSCP
  6. Sambung hardware sesuai tabel Wiring di atas
  7. Uji bertahap: 01 → 02 → sudo 03 → sudo 04
📖 Panduan lengkap: PANDUAN_UJI_RASPI_LENGKAP.txt (Fase 0–8)

🅒 RPi & HMI sudah siap, mau langsung demo

  1. Di RPi: sudo python3 04_decy13_mqtt_daemon.py
  2. Di Mini PC: buka Chrome → buka index.html
  3. Tab Konfigurasi Broker MQTT → URL: ws://[IP_RPi]:9001
  4. Klik Hubungkan ke Raspberry Pi → indikator hijau
  5. Ikuti urutan 7 tahap di atas!
☑️ Cek dulu: CHECKLIST_COMMISSIONING.txt sebelum demo!

❓ FAQ Cepat

Q: Animasi HMI tidak bergerak meski sudah klik Power?
A: Periksa apakah MQTT sudah terhubung (indikator hijau di header HMI). Jika masih amber, klik Hubungkan di tab Konfigurasi Broker.
Q: LED tidak menyala saat daemon jalan?
A: Pastikan: (1) audio sudah OFF di /boot/config.txt, (2) jalankan dengan sudo, (3) resistor 330Ω terpasang di jalur DIN.
Q: MQTT HMI tidak bisa connect ke RPi?
A: Cek (1) Mini PC & RPi di jaringan sama, (2) ping [IP_RPi] dari Mini PC berhasil, (3) Mosquitto aktif (port 9001 WebSocket).
Q: Bisa demo tanpa hardware RPi dulu?
A: Ya! Gunakan 05_laptop_dryrun_simulator.py di laptop. Lihat panduan PANDUAN_DRYRUN_LAPTOP_WINDOWS.txt.
